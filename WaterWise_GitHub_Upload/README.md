# BUS5001 Q4 — NotebookLM evaluation

## Scenario and scope
A student uses NotebookLM to prepare an ESG training briefing about WaterWise from two simulated coursework sources. The NotebookLM interactions are demonstrated in the screenshots dated 12 October 2026. The 20 WaterWise sessions described in the sources are invented exercise data, not actual chatbot tests or university results.

This repository records source-based question answering, numerical interpretation, synthesis into a briefing, citation checking and saving a response as a note. It does not claim to test every NotebookLM feature or demonstrate university-wide integration.

## Files
- EXPERIMENT_LOG.md: prompts, observed results, checks and critical reflections.
- EXECUTIVE_BRIEFING.md: the final 150-word output, with original citation numbers.
- SOURCE_EXTRACTS.md: available source excerpts and provenance limitations.
- evidence_01_limitations.png: output discussing evidence limits.
- evidence_02_initial_briefing.png: initial briefing before clarification.
- evidence_03_revised_briefing.png: explicit invented-data clarification.
- evidence_04_saved_note.png: complete saved briefing.
- evidence_05_source_check.png: source figures supporting manual checks.

## Evidence quality
The screenshots are unchanged copies with descriptive filenames. The log was compiled on 13 October 2026 from the supplied screenshots and conversation outputs; it is a retrospective log, not an automatically captured execution trace. No timing, user-satisfaction or learning-gain measurements were collected.

The complete original source documents were not available when this pack was assembled. SOURCE_EXTRACTS.md identifies what is visible and what still requires the original documents. Do not describe this pack as containing verbatim copies of both complete sources.
